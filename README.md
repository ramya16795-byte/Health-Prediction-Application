# Health-Prediction-Application
Health Prediction Application
Project Description

This is a Health Prediction Application developed using Python, Tkinter, SQLite, and AI API integration. The application allows users to manage patient records and generate health risk predictions based on blood test values.

Features

Create patient records
View patient records
Update patient records
Delete patient records
Input validation
SQLite database storage
AI-powered health prediction
User-friendly Tkinter interface

Technologies Used

Python
Tkinter
SQLite
Requests Library
External AI API

Database Fields

Full Name
Date of Birth
Email Address
Glucose
Haemoglobin
Cholesterol
Remarks

How to Run

Install Python.
Install required packages:
pip install requests
Run:
python main.py
